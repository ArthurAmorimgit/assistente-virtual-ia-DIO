# 💰 Edu - Assistente Virtual de Educação Financeira

Projeto desenvolvido para o desafio da DIO: **Construa Seu Assistente Virtual Com Inteligência Artificial**.

## 🎯 Objetivo
Ajudar pessoas a entenderem conceitos básicos de finanças pessoais de forma acessível e segura, evitando alucinações de IA através de dados estruturados.

## 🛠️ Tecnologias
- Python 3
- Google Gemini API (`gemini-2.5-flash`)
- Streamlit (Interface Web)

## 🚀 Como Executar
1. Clone o repositório
2. Instale as dependências: `pip install -r requirements.txt`
3. Crie o arquivo `.env` e insira sua `GEMINI_API_KEY`
4. Execute a aplicação: `streamlit run src/app.py`
